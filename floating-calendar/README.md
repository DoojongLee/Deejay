# Floating Calendar 📅

항상 화면 위에 떠있는 **개인 구글 캘린더** 미니 창입니다.
회사 아웃룩 데이터는 전혀 건드리지 않습니다 — 그냥 내 구글 캘린더를 작은 창으로
항상 위에 띄워두어, 아웃룩과 **나란히 보기** 위한 도구입니다.

> 이 앱은 캘린더를 **보여주기만** 합니다. 어떤 데이터도 읽거나, 옮기거나,
> 외부로 보내지 않습니다. 아웃룩/회사 시스템과 연결되지 않습니다.

## 기능

- 🪟 항상 위에 떠있는(always-on-top) 작은 창
- 🔒 로그인 세션 유지 (한 번 로그인하면 재실행해도 유지)
- 🎚️ 투명도 조절 (상단 △ / ▽ 버튼)
- 📌 고정 켜기/끄기
- ⌨️ 전역 단축키 `Ctrl + Shift + C` 로 보이기/숨기기
- 🗔 트레이 아이콘 (클릭=토글, 우클릭=메뉴, 종료)
- 💾 창 위치/크기/투명도 자동 저장

## 실행 방법

필요: [Node.js](https://nodejs.org) (LTS 권장)

```bash
cd floating-calendar
npm install      # electron 다운로드 (최초 1회, 수십 MB)
npm start
```

처음 실행하면 구글 로그인 화면이 나옵니다. 로그인하면 이후에는 유지됩니다.

## 조작

| 위치 | 동작 |
|------|------|
| 상단 바 드래그 | 창 이동 |
| 창 모서리 드래그 | 크기 조절 |
| △ / ▽ | 투명도 진하게 / 투명하게 |
| ⟳ | 새로고침 |
| 📌 | 항상 위 고정 토글 |
| — | 트레이로 숨기기 |
| ✕ | 완전 종료 |
| `Ctrl+Shift+C` | 보이기/숨기기 (어디서나) |
| 트레이 아이콘 클릭 | 보이기/숨기기 |

## 배포용 실행파일 만들기 (선택)

설치 없이 실행되는 파일을 만들려면:

```bash
npm run dist
```

- Windows → `dist/` 에 포터블 `.exe`
- macOS → `.dmg`
- Linux → `.AppImage`

## 로그인이 막힐 때

구글이 간혹 임베디드 브라우저 로그인을 막는 경우가 있습니다. 이 앱은 일반 Chrome
User-Agent 로 위장해 대부분 통과하지만, 그래도 "이 브라우저는 안전하지 않습니다"가
나오면:

1. 평소 쓰는 Chrome/Edge 에서 먼저 구글에 로그인해 둔 뒤 다시 시도하거나,
2. 창 안에서 구글 계정 로그인 대신 **이미 로그인된 상태**로 `calendar.google.com` 이
   바로 열리도록 기다려 보세요.

## 보안 참고

- `partition: persist:gcal` 세션은 이 앱 전용으로 격리되어 로컬에 저장됩니다.
- 외부 링크(구글 외 도메인)는 기본 브라우저로 열립니다.
- 네트워크 통신은 오직 구글 캘린더(google.com)와만 이루어집니다.
